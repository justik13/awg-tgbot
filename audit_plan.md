# Аудит и план улучшений скрипта awg-tgbot.sh

## Текущее состояние

### Проблема с Platega Webhook URL
- **Текущий URL**: `https://<IP>:8081/webhook`
- **Проблема**: Platega не принимает IP-адреса с нестандартными портами
- **Требование**: Нужен домен с HTTPS на порту 443

### Текущая логика настройки Platega (строки 2082-2178)
Запрашивает:
1. Merchant ID
2. Secret Key
3. Тестовый режим
4. Порт webhook (по умолчанию 8081)
5. Цены на подписки

**Не хватает**:
- Запроса доменного имени
- Автоматической установки Nginx
- Автоматической настройки SSL (Certbot)
- Проверки состояния firewall

## Детальная реализация

### Функция 1: check_and_configure_firewall()
```bash
# Проверяет ufw и firewalld
# Если активен - открывает порты 80/tcp и 443/tcp
# Если не активен - пропускает
# Логгирует действия
```

### Функция 2: install_and_configure_nginx()
```bash
# Проверяет наличие nginx
# Если нет - устанавливает
# Создает конфиг /etc/nginx/sites-available/platega-webhook
# Настраивает reverse proxy на localhost:8081
# Включает сайт и перезагружает nginx
```

### Функция 3: obtain_ssl_certificate()
```bash
# Проверяет наличие certbot
# Если нет - устанавливает certbot и python3-certbot-nginx
# Запускает certbot --nginx -d <domain>
# Настраивает автообновление через systemd timer
```

### Функция 4: validate_domain_dns()
```bash
# Проверяет A-запись домена
# Сравнивает с SERVER_IP
# Предупреждает о несоответствии
```

## Безопасность

1. **Firewall**: Открывать порты только если firewall активен
2. **DNS validation**: Предупреждать если домен не указывает на этот IP
3. **Nginx config**: Ограничить доступ к /webhook только для Platega (опционально IP whitelist)
4. **SSL**: Настроить редирект HTTP→HTTPS
5. **Откат**: Сохранять старые конфиги перед заменой
